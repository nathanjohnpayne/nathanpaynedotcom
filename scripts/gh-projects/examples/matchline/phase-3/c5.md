Umbrella for bugs and friction Nathan hits during real use. Split into per-bug sub-issues as they come up; this ticket tracks the umbrella.

**Intake rules:**

- Any bug that breaks the core loop (extract / match / generate / validate / export) is P0 and jumps the queue.
- Any violation of zero-fabrication is a P0 and blocks the phase from closing.
- Friction (UX papercuts, copy nits, "I wish it did X") goes on the umbrella as a sub-bullet and gets promoted to its own ticket only if Nathan hits it again.
- Ideas for Phase 4 / V2 get a label (`v2-candidate`) and a one-liner; do not expand into full tickets here.

**Process:**

- Nathan notes the bug in the moment (Apple Notes, Granola, whatever's fast). End of day or end of session, transcribe to sub-issues.
- Each sub-issue has: what broke, what was happening, expected behavior, steps to reproduce if not obvious, priority (P0/P1/P2).
- Sub-issues get fixed via normal PR flow per `CLAUDE.md`.

**Exit criterion** (for this umbrella): phase ends when the Phase 3 milestone ticket closes. Remaining P2 items roll to a V2 backlog.
