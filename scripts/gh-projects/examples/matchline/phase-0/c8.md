**Human action.** Functions `functions/src/llm/anthropic.ts` and `functions/src/llm/openai.ts` read their API keys via `defineSecret` from Firebase Functions secrets. The secrets have to exist before any function listing them will deploy.

**Blocks on:** #__C1_NUM__ (Firebase project exists).

**Scope:**

Get keys from your Anthropic and OpenAI accounts (dashboard → API keys → create). Then:

```bash
firebase functions:secrets:set ANTHROPIC_API_KEY --project matchline-dev
# Paste the key when prompted. The CLI stores it in Secret Manager.
firebase functions:secrets:set OPENAI_API_KEY --project matchline-dev
```

**Budget guardrails before you paste the keys:**
- In the Anthropic console, set a monthly spend cap for the workspace you generate the key under.
- In the OpenAI dashboard, set a usage limit on the key.

The PRD caps per-application cost at $1; setting a hard spend cap on each provider account means a bug that runaway-loops a prompt can't exceed your tolerance.

**Verification:**
- `firebase functions:secrets:access ANTHROPIC_API_KEY --project matchline-dev` returns the stored key.
- Both secrets show up in `firebase functions:secrets:list`.
