**Human action.** Set up the per-project deployer service account and 1Password-backed impersonation so deploys don't require interactive `gcloud auth login`.

**Blocks on:** #__C1_NUM__ (Firebase project exists).

**Scope:**

```bash
cd ~/Documents/GitHub/matchline   # or wherever matchline is cloned
op-firebase-setup matchline-dev
```

This creates `firebase-deployer@matchline-dev.iam.gserviceaccount.com`, grants deploy roles, and configures your local `gcloud` + `op-firebase-deploy` wrappers to impersonate it. Full details in `DEPLOYMENT.md` § "New Project Setup".

**Verification:**
- `gcloud iam service-accounts list --project=matchline-dev` shows the deployer SA.
- Until Phase 1 content exists: `op-firebase-deploy --only hosting --dry-run` succeeds.
- Once there's something deployable: `op-firebase-deploy --only hosting` does a real build + deploy successfully.
