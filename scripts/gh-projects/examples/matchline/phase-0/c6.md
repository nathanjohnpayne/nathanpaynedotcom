**Human action.** Create the live Firebase project that `matchline-dev` in `.firebaserc` points at. `firebase deploy` will fail until this exists.

**Scope:**

```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
firebase projects:create matchline-dev --display-name "Matchline (dev)"
# Optional; only if you want a prod project now:
# firebase projects:create matchline-prod --display-name "Matchline"
```

Then in the [Firebase console](https://console.firebase.google.com/project/matchline-dev), enable:
- **Authentication** (Email/Password or Google, whichever you prefer for V1).
- **Firestore** (start in production mode — rules are already committed).
- **Hosting**.
- **Cloud Functions** — requires Blaze billing plan. Attach to your billing account.
- **Storage** (optional for V1; skip until an export feature needs it).

**Verification:**
- `firebase use` inside the matchline repo resolves to `matchline-dev`.
- `firebase functions:list` returns (empty is fine) — not "project not found".
