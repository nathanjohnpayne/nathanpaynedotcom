Tracks **Phase 2** of Matchline V1 (Project #6).

**Goal:** turn the core loop into the product Nathan actually wants to run his search with. Phase 1 proves the loop works for resumes; Phase 2 adds the inputs and outputs that make it a real pipeline.

Scope, from the PRD's Sprint 2:
- LinkedIn HTML parser (paste view-source → Experience Units via the same extraction pipeline).
- Long-form career context parser.
- Cover letter generation (same validation layer).
- Application Editor traceability polish.
- Pipeline Kanban.
- Export to PDF, DOCX, plain text.
- Tasks + follow-up reminders sidebar.
- Capability Graph JSON export (portability is a V1 technical principle).

**Exit criterion** (from PRD § What ships first → Sprint 2):

> Nathan uses Matchline as the primary tool for his first real application.

Not "can use"; uses. The phase closes when one real application ships end-to-end through Matchline.
