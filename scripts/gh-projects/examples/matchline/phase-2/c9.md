2. **Run the full loop.**

   - Generate the cover letter; same validation walk.
   - Export DOCX + PDF of both.

   - Mark the Application `stage = Applied` in the Pipeline.

**Exit criteria:**
- One real application shipped.
- Zero fabrication in either output.
- Nathan signs off that both output feel like his work.
- Pipeline + Editor + Export work without manual fallback (no exporting to Google Docs to finish formatting).
