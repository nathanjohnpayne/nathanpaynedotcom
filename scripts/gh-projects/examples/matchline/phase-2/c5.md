# Pipeline Kanban (7 stages, cards, click-through to Role Detail)

The CRM-lite view that lets Nathan run the search without a spreadsheet. Kanban by `ApplicationStage`.

**Scope** (`src/routes/Pipeline.tsx` replaces the Sprint 0 placeholder — the stages scaffold is already there, the content isn't):

1. **Columns.** Seven columns matching `ApplicationStage`:
   `Saved → Drafting → Applied → Interviewing → Offer → Rejected → Withdrawn`.

2. **Cards.** Each Application renders as a card. Fields:
   - Company + title (from the linked Role → Company).
   - Days in current stage (computed from `last_activity_at`).
   - Next action (first unresolved task from the task sidebar, sorted `due_at ASC NULLS LAST` then `created_at ASC` — see the tasks-sidebar ticket later in this phase).
   - Key contact (most recent `Interaction`'s `Person`, if any).

3. **Drag-and-drop.** Moving a card between columns updates the Application's `stage` and `last_activity_at`. Optimistic UI; rollback on write failure.

4. **Click-through.** Card click → Role Detail for the underlying Role.

5. **Empty-state copy.** Each column has a short, useful empty state (e.g. "No applications in Interviewing. This is where live processes land when you hear back.") — not marketing copy.

6. **Responsive.** At desktop width (primary target) columns sit side-by-side. Below `md`, the board collapses to a vertical stack with column headers as pills.

**Non-goals:**
- Custom stages — the seven listed are V1 final.
- Card customization — fields are fixed.
- Team boards — single-user.

**Verification:**
- Drag a card from Saved → Applied, reload, state persists.
- Cards show sensible "days in stage" from `last_activity_at`.
- Accessibility: keyboard can move cards between columns (arrow-key alt to drag).
