The quality bar is defined in the PRD; this ticket turns it into a CI-runnable harness.

**Quality bars** (from PRD § Success metrics → Quality metrics):

- **Experience Unit extraction:** ≥ 80% of extracted Units are accurate and useful without user editing, across a test set of 10 resumes.
- **Match accuracy:** ≥ 80% of proposed matches between Experience Units and Job Requirements hold up to manual review.
- **Zero fabrication:** no generated application contains a claim that can't be traced to an approved Experience Unit. Hard constraint.

**Scope:**

1. **Fixtures.** `tests/fixtures/resumes/*.txt` (10 resumes — Nathan's plus 9 others; synthetic or from publicly-sharable sources). `tests/fixtures/jds/*.txt` (10 JDs). `tests/fixtures/expected/*.json` — hand-curated reference extractions and match annotations.

2. **Extraction accuracy test.** Run extraction on every fixture resume, diff against expected. Accuracy metric = 1 − edit distance on the normalized Unit set, aggregated. Fail if < 80% on the test set average.

3. **Match accuracy test.** Run matching on every fixture (resume × JD) pair. Compare top-K matches against hand-curated "good matches" set; accuracy = intersection / |expected|. Fail if < 80% average.

4. **Zero-fabrication invariant test.** Run full pipeline on every fixture pair. For every claim in every generated resume, assert it traces to an approved Unit. Any un-traced claim fails the suite.

5. **CI wiring.** Add `npm run test:eval` target. Run in `repo_lint.yml` on PR. Gate merge on the three quality bars.

6. **Cost + latency reporting.** The harness emits per-fixture cost and latency to stdout; aggregate stats printed at end. Not a gate in Phase 1 (that's Phase 3), just visibility.

**Non-goals:**
- Outcome tracking / learning loop — requires V2 data volume.
- User-specific accuracy (single-user V1).

**Verification:**
- Harness runs end-to-end green against the seed fixture set.
- One deliberately-broken fixture (fabricated claim) fails the zero-fab test — confirms the test catches what it claims to.
