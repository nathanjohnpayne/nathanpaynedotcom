Generate a resume from approved matches. Controlled-generation pattern: the model gets approved Units as ground truth and is instructed to synthesize only from what's provided.

**Blocks on:** #__C1_NUM__ (approved matches exist to pass into generation).

**Scope:**

1. **Functions endpoint.** `functions/src/generation/resume.ts` exposes `generateResume(applicationId)`. Reads the Application, pulls `approved_unit_ids` + the matches that point at them, assembles a `UnitCluster` per resume section (summary, bullets), calls `modelFor("generation")` (Haiku per PRD — bulk generation stage).

2. **Prompt.** `functions/src/prompts/resume-generation.md`. System prompt instructs: "Use only the Experience Units provided. Do not introduce skills, tools, or claims that are not in the input. If a Requirement cannot be matched from the provided Units, acknowledge the gap or leave the Requirement-linked bullet empty — do not invent." User turn supplies the approved Units (full Unit objects, including raw_text for grounding) and the Role + Requirements for targeting.

3. **Output shape.** Structured output: `{ summary, experience: [{ title, company, date_range, bullets: [{text, source_unit_ids: string[]}] }], skills, education }`. Every generated bullet carries the ids of the Units it was grounded on. This is the input to the validation layer (the next ticket in this phase).

4. **Persistence.** Write the generated resume to an `AssetRef` under the Application's `generated_assets`. Format `"json"` for now; file exports are Phase 2 (#c6).

5. **Cost + latency logging.** Record tokens in / tokens out / cost / duration on the AssetRef for per-application budget tracking (spec § Execution targets, Phase 3 dashboard).

**Non-goals:**
- Cover letters (Phase 2 cover-letter-generation ticket).
- Outreach drafts (Phase 2+).
- Tone tuning (Phase 3 generation-prompt-tuning ticket).

**Verification:**
- Generated output's `source_unit_ids` on every bullet reference only approved Units for that Application.
- p95 ≤ 8 s per spec § Execution targets.
- Cost ≤ $0.30 per generation (logged).
