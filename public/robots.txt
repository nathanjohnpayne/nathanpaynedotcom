# IMPORTANT — this file is not necessarily the whole policy. Cloudflare sits in
# front of Firebase Hosting and CAN prepend a "# BEGIN Cloudflare Managed

# cannot be removed by editing this file; it is toggled in the Cloudflare
# dashboard. A permissive file here would not mean a permissive policy in
# production.
#
# As of 2026-08-19 that managed block is DISABLED, so the served file is this
# file verbatim. Do not assume that stays true — verify at the public served
# endpoint (the response comes from Cloudflare, not the origin):
#   curl -fsS https://nathanpayne.com/robots.txt
