# Decision (2026-08-19, issue #615): ALL crawlers and bots are allowed,

# IMPORTANT — this file is not the whole policy. Cloudflare sits in front of

# removed by editing this file; it is toggled in the Cloudflare dashboard.
# A permissive file here does not mean a permissive policy in production.

#   curl -s https://nathanpayne.com/robots.txt
