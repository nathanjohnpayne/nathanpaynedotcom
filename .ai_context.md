# AI Context — nathanpayne.com

## Project Name
nathanpayne.com

## Project Type
Static personal portfolio site (no build step, no framework, no package manager)

## Primary Languages
- HTML5
- CSS3
- JavaScript (Vanilla ES6+, IIFE-wrapped)

## Key Entry Points

| File | Purpose |
|------|---------|
| `index.html` | Complete site — markup, SEO meta, Open Graph tags, GA4 snippet, font preconnects |
| `style.css` | All styles — Mondrian grid, panel states, motion system, responsive breakpoint, accessibility |
| `script.js` | All interactions — panel open/close, keyboard nav, hover intent, scroll guard, analytics |
| `firebase.json` | Firebase Hosting config — cache headers, security headers, deploy ignore rules |
| `AGENTS.md` | AI agent instructions and behavioral rules |

## Directories With Non-Obvious Purpose

| Directory | Purpose |
|-----------|---------|
| `og/` | Platform-specific Open Graph images (LinkedIn, Twitter/X variants) |
| `rules/` | Repository-level invariants enforced on all agents and contributors |
| `plans/` | Feature rollout and migration plans |
| `specs/` | Feature specifications and acceptance criteria |
| `scripts/ci/` | CI enforcement scripts (run locally before commits; no CI pipeline currently connected) |

## Directories Intentionally Absent

| Directory | Justification |
|-----------|--------------|
| `src/` | All source files (`index.html`, `style.css`, `script.js`) live at the repository root. No subdirectory structure is needed for a three-file site. |
| `tests/` | Static site with no application logic. No unit or integration test framework applies. Add when a testing approach is established. |
| `functions/` | No serverless or cloud functions. Static site served directly from Firebase Hosting. Add if backend functions are introduced. |
| `dist/` | No build step exists. Static files are deployed directly from source. Add if a build step is introduced. |
| `docs/` | README.md, AGENTS.md, and DEPLOYMENT.md serve all documentation needs at this project scale. |

## External Dependencies

| Service | Purpose |
|---------|---------|
| Firebase Hosting | Static file hosting and CDN at nathanpayne.com |
| Google Analytics 4 | User engagement analytics (Measurement ID: `G-7C29SRBXB1`) |
| Google Fonts | Cormorant Garamond (serif) and Inter (sans-serif) typefaces |
| 1Password CLI (`op`) | Credential management for non-interactive Firebase deploys |

## Do Not Touch

| File/Path | Reason |
|-----------|--------|
| `.firebaserc` | Firebase project binding — changing this changes which project you deploy to |
| `firebase.json` | Cache-control, security headers, and deploy ignore rules — changes affect CDN behavior |
| `og-image.png` | Primary OG image — replace only with explicit design approval |
| `og/` | Platform-specific OG images — replace only with explicit design approval |
| `inspiration.jpg` | Design reference file; not deployed (excluded via `firebase.json`). Do not commit changes to this file. |

## Standard Compliance Notes

- **`src/` absent:** Intentional. Three-file site with source at root. Documented above.
- **`tests/` absent:** Intentional. No test framework for a static site. Documented above.
- **`functions/` absent:** Intentional. No serverless functions. Documented above.
- **`dist/` absent:** Intentional. No build step. Documented above.
- **`docs/` absent:** Intentional. All documentation fits in canonical root files. Documented above.
- **`scripts/ci/` present but not connected to CI:** CI enforcement scripts exist per the standard. No CI pipeline is connected. Run scripts locally before commits.
- **`.cursor/rules/deploy.mdc`:** Valid Cursor configuration file providing deploy context to the Cursor agent. Mirrors `DEPLOYMENT.md`.
- **`.cursor/rules/project-conventions.mdc`:** Valid Cursor configuration file. Note: the deploy instruction in this file ("Deploy with `firebase deploy`") is outdated — the correct command is `op-firebase-deploy`. This discrepancy should be corrected in a future update to the `.mdc` file.
