nathanpayne.com

### Load-bearing npm dependencies that look removable

`@astrojs/markdown-remark` is a required devDependency that **no source file imports**. It backs the `markdown.remarkPlugins` / `markdown.rehypePlugins` hooks in `astro.config.mjs`, which is how the three custom plugins in `src/plugins/` run. A dependency-graph scan will report it as unused; removing it breaks `astro build`. `astro` and `@astrojs/markdown-remark` are both pinned to the exact same version (`7.2.2`), because Astro declares the latter as an exact-version peer; they move together or not at all. Separately, `typescript` is declared as the bounded range `>=6.0.3 <6.1.0`, not a caret range, because `typescript-eslint` peers `<6.1.0`. All three constraints, and the procedure for changing them, are specified in `rules/repo_rules.md` § Toolchain Constraints—that file is authoritative, this note only exists so the dependency is discoverable from the inventory.

### Markdown parser packages used by the content lint gate

`scripts/lint-content-em-dash.mjs` declares four direct devDependencies that no
page or component imports: `mdast-util-from-markdown`, `mdast-util-gfm`,
`micromark-extension-gfm`, and `decode-named-character-reference`. They let the
gate scan what the Markdown *renders* rather than its raw source, which is what
keeps code blocks, tables, and link destinations out of the lint and catches a
dash padded through inline markup or a character reference. All four already
shipped inside the tree as Astro transitives, so declaring them added three
lines to the lockfile; they are direct dependencies because the script imports
them directly, and a dependency-graph scan of `src/` alone will report them as
unused. `unist-util-visit` is separately required by `src/plugins/`.

## Standard Compliance Notes

- **`src/` present:** Astro source directory containing pages, layouts, content collections, plugins, integrations, and styles.
- **`dist/` present but gitignored:** Build output from `astro build`. Deployed to Firebase Hosting.
- **`public/` present:** Static assets (favicons, robots.txt, OG fonts) copied verbatim into `dist/` at build time.
- **`functions/` absent:** Intentional. No serverless functions. Documented above.
- **`docs/` present:** Extended documentation (agent processes, deployment guides). Documented above.
- **`scripts/ci/` present:** CI enforcement scripts run by GitHub Actions workflows.
- **`.cursor/rules/deploy.mdc`:** Valid Cursor configuration file providing deploy context to the Cursor agent. Mirrors `DEPLOYMENT.md`.
- **`.cursor/rules/project-conventions.mdc`:** Valid Cursor configuration file providing project conventions to the Cursor agent.
