| Directory | Justification |

## Standard Compliance Notes

- **`src/` absent:** Intentional. Static site source lives directly in the repo root plus `projects/`. Documented above.
- **`blog/` present:** Intentional. Generated static blog routes are checked in so Firebase Hosting can serve them directly without a runtime renderer.
- **`functions/` absent:** Intentional. No serverless functions. Documented above.
- **`dist/` absent:** Intentional. There is no bundled build output directory. Generated blog pages are checked in directly under `blog/`.
- **`docs/` present:** Extended documentation (agent processes, deployment guides). Documented above.
- **`scripts/ci/` present but not connected to CI:** CI enforcement scripts exist per the standard. No CI pipeline is connected. Run scripts locally before commits.
- **`.cursor/rules/deploy.mdc`:** Valid Cursor configuration file providing deploy context to the Cursor agent. Mirrors `DEPLOYMENT.md`.
- **`.cursor/rules/project-conventions.mdc`:** Valid Cursor configuration file providing project conventions to the Cursor agent.
