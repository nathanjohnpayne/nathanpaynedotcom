# Production Capture Summary, 2026-10-08

Sanitized evidence for [`inventory.md`](inventory.md) (#1227, part of #1079). Raw request bodies, cookies, identifiers, and tokens stayed in a scratch directory outside the repository. This file records only shapes, property names, hosts, hashes, and the method. Every value that could identify the test browser or the site's accounts is replaced with a placeholder: `<token>` (PostHog project token), `<measurement ID>` (GA4), `<site token>` (Cloudflare Web Analytics).

## Method

A Playwright script drove Chromium 153.0.8010.12 (headless, desktop viewport 1440×1000, `en-US`, `America/Los_Angeles`) through eight production pages in one browser context, in this order: `/`, `/blog/`, `/blog/autofix-was-the-whole-cost/`, `/projects/`, `/projects/mergepath/`, `/projects/swipe-watch/` (the Mux hero), `/resume/`, and `/projects/override/?utm_source=tracka-probe&probe_param=tracka-probe-value#tracka-probe-fragment` (a probe URL to observe query and fragment handling). On each page it waited about ten seconds, moved the mouse, scrolled, and on the homepage hovered and clicked panels.

Egress control, as used for the run summarized here (run 3):

- Service workers blocked (`serviceWorkers: 'block'`).
- A context-wide catch-all route installed before the first navigation. Allowlisted requests were fetched by Node and fulfilled into the page: the site's own `GET` pages and assets on `https://nathanpayne.com`, PostHog `GET /static/*.js` and `GET /array/<token>/config.js` on `https://d.nathanpayne.com`, `GET https://www.googletagmanager.com/gtag/js`, and `GET https://static.cloudflareinsights.com/beacon.min.js/*`. Collection requests (every other PostHog request, every Google Analytics, DoubleClick, and Google Ads host, and Cloudflare `/cdn-cgi/rum`) were answered by an in-process sink that stored and decompressed the body and never forwarded it. Everything else was aborted.
- The browser's HTTP and `CONNECT` traffic went through a local proxy that refuses every connection and logs the target host. Because allowlisted requests were fetched by Node, not by the browser, an HTTP request the route never saw had nowhere to go. This run predates the WebRTC rule, so it does not establish that non-proxied WebRTC UDP was disabled; the site's own code makes no WebRTC calls (`RTCPeerConnection` appears nowhere in `src/` or `public/`), and third-party scripts were not audited for it.
- Collection-only hosts (`*.google-analytics.com`, `*.analytics.google.com`, `*.doubleclick.net`, `*.posthog.com`, `cloudflareinsights.com`, `*.litix.io`, `a.nel.cloudflare.com`) were also mapped to `NOTFOUND` in Chromium's resolver, and Chromium's Reporting and NEL features were disabled.
- PostHog's bot filter reads `navigator.userAgentData.brands`, which reports `HeadlessChrome` in headless mode, and `navigator.webdriver`. The run presented an ordinary Chromium brand list and `webdriver: false` so the SDK behaved as for a real visitor. With the headless brand (run 1), PostHog loaded but sent no events at all.

A control `navigator.sendBeacon` from a live page reached the route. A second control showed that a beacon or `keepalive` fetch sent from a `pagehide` or `visibilitychange` handler does **not** reach a Playwright route: in a local-only test, the route saw neither unload request while the local server received both. The refusing proxy closes that gap; test harnesses for #1079 need the same arrangement (see [Escape Incident](#escape-incident)).

## Escape Incident

The first two runs used Playwright routing and resolver blocks, but not the refusing proxy. Requests sent from `pagehide` and `visibilitychange` handlers bypass Playwright routing (shown by the local control above), so on each page exit the browser could reach any host the resolver did not block.

- **PostHog:** the PostHog project's `raw_session_replay_events` table holds one row for the run-2 test session: one replay event at 19:13:59 UTC, when the browser left `/projects/swipe-watch/`. The `events` table holds zero events for either test session or distinct ID, and zero events in the six hours after the runs carrying the test browser's version, user agent, or probe URL (checked by SQL, with a positive control showing the same day's real events).
- **Cloudflare Web Analytics:** the unload beacon to `nathanpayne.com/cdn-cgi/rum` was not blocked in runs 1 and 2. The zone's RUM dataset (GraphQL `rumPageloadEventsAdaptiveGroups`) shows no page loads between 19:05 and 20:30 UTC; the same query returns page loads earlier the same day.
- **GA4 and Mux Data:** unload hits to `www.google-analytics.com` and `inferred.litix.io` were resolver-blocked in runs 1 and 2 (both hosts are covered by the `NOTFOUND` map), so they could not connect.
- Run 3, summarized above, refused all 18 unload-time connections at the proxy.

The single PostHog replay row is the only analytics record known to have been created. Deleting it is a vendor-side write, so it is left for Nathan.
