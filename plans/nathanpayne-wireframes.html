nathanpayne.com — as-built wireframes, every page at every width it renders at

An as-built reference, not a proposal. Each frame draws the site exactly as main builds it today, painted with the shipped tokens from src/styles/global.css: the Mondrian/De Stijl homepage with its four focus states, and the inner pages on their framed reading canvases. Every page is authored once as a function returning markup and stamped at desktop (1440×900), tablet (834×1112) and phone (390×844), drawn as a macOS window, an iPad and an iPhone with the device chrome outside the canvas so the container width stays exact. The iPhone's status bar (62pt with the Dynamic Island, measured from an iPhone capture and Apple's iOS UI kit) takes the top of its 844, leaving a 390×782 canvas, and is filled with the page's root background as Safari shows it: chrome gray, or red behind the homepage stack. Safari's bottom toolbar floats over the page, as it does on the device. The canvas is a CSS size container, so the same markup re-flows per width and per height with @container rules written to the site's own breakpoints (--bp-narrow 480, --bp-tablet 768, --bp-stack 1024 and the homepage's 840px height floor). Renditions that exist only at particular sizes get their own frames: the homepage's four open panels at 1440, the 1440×700 short window that the height axis sends to the stack, and the résumé's print layout on a Letter sheet.

Every frame carries a stable anchor of the form #fx-<page>-<rendition>. Captions name the breakpoint behaviour the frame shows. Copy is the public site copy, shortened where a frame would overflow; the gray hatched blocks stand in for screenshots and logos, which are the only things not drawn from source. Sources are listed in the file's header comment and under Tokens.

Homepage stack: cover + reading surfaces (#1481). Below 1024px wide or 840px tall, only the name, tagline and NOW stay on the red plane; Context, Approach, Writing and the three other panels sit on paper blocks with rails that cycle from the cover (blue, yellow, black, red), as the inner pages have since #1479. Connect closes on cream.

How to read a frame.
· Chips name the canvas (desktop 1440×900 · short 1440×700 · tablet 834 · phone 390 · print Letter) and whether the frame is a built page or a state of one (an open panel, the notice overlay).
· Numbered legends under a page apply to all its frames.
· Zoom scales the desktop and tablet canvases; the phone canvas is 1:1 by default. Nothing inside re-flows when you zoom — only the real width and height do that. Tall pages are clipped at the frame's height, as a first screen would be.
